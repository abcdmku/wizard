The dev UI is reworked. A run page shows one status in the same words everywhere, a summary of any step you click, and cards that name the step behind each service call, its attempt and its item. Timers are named and listed apart from what waits on you. History reads as plain sentences, with every event one switch away. A wizard page leads with the graph and a Start run form, and lists steps and schemas in a readable form. "Stop and resume" is now "Restart from snapshot", under More.
