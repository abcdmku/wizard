# Collect form input

Read [Steps and kinds](/concepts/steps) and [Results as values](/concepts/results) first. The
example creates one `FlowRun`, validates a form draft, and finishes the run.

```ts file="packages/docs/snippets/guides/human-form.ts"
```

`setInput` updates the active view draft. `next` checks the view schema and leaves the view only
when the draft is valid. Both methods return failures as values.

For a browser UI, keep the `FlowRun` on the server and connect a projection through the
[React integration](/integrations/react). See [`@openwizard/core`](/api/core) for the full
`FlowRun` API. The [happy-path example](/examples/01-happy-path) adds a service task and tests.
