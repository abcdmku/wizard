# Tracing

Record a run as OpenTelemetry spans.

```ts file="packages/docs/snippets/advanced/tracing.ts"
```

- `instrumentRun(run)` opens one span for the run, one for each attempt of a step, one for each undo and one for each child run. A failure sets the span status.
- Your application sets up the OpenTelemetry SDK and exporter. Without one, the calls do nothing.
- Spans carry ids, step names, event names and counters. They never carry context, input, output, payloads, idempotency keys or error messages.
- Call `telemetry.stop()` before `run.dispose()`.

## Join the trace of a request

| Goal | Call |
|---|---|
| Make the run a child of the current request | `instrumentRun(run, { parentContext })` |
| Link a resumed run to its earlier trace | `instrumentRun(run, { resumeContext })` |
| Link an incoming event to its sender's trace | `telemetry.send(event, payload, { context, eventId })` |
| Pass the run's trace to a service you call | `telemetry.inject(headers)` |
| Read trace headers from a request | `telemetry.extract(headers)` |

## Read a trace without a collector

`formatTrace(run.log())` prints the same events as text. See [Inspect and debug](/guide/inspect).
