# Inspect and debug

Print what a wizard does, and ask a run why it is stuck.

```ts file="packages/docs/snippets/learn/inspect.ts"
```

| Question | Call |
|---|---|
| What does this wizard do? | `toMarkdown(inspect(wizard))` prints a diagram, a table of every step, the events and the warnings |
| Is the definition sound? | `inspect(wizard).warnings` |
| Why has this step not started? | `run.explain(step)` returns its `status`, `phase` and `reasons` |
| What is the run waiting for? | `run.waitingFor()` lists views, event waits and sleeps, including those of children |
| What happened so far? | `formatTrace(run.log())` prints one line per event |

- `inspect` returns the manifest, the same facts as JSON. Neither call runs your functions, so give the wizard and each step a `description`. `toMarkdown` prints it.
- A broken definition throws `WizardError` with code `DEFINITION_INVALID` when the module loads. The message lists every problem.
- `run.log()` keeps the last 200 events. Raise `logSize` in the run options, or collect them all with `run.observe(listener)`.

## Read the reasons

| Reason | Meaning |
|---|---|
| `not-activated` | Nothing has started the step yet |
| `deps-unmet:<step>` | It needs `<step>`, which has no output yet |
| `retrying` | It waits for its next attempt |
| `failed:interrupted` | The process stopped while it ran |
| `run-halted` | A step failed. Retry or skip that step first |
| `auto-run-manual` | The wizard sets `autoRun: 'manual'`. Call `run.startReady()` |
