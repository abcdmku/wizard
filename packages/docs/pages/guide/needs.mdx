# Pass data between steps

Give a step the typed output of earlier steps with `needs`.

```ts file="packages/docs/snippets/learn/needs.ts"
```

- Create the producing steps first, then list them in `needs`. Every function of `summary` receives `needs.profile` and `needs.orders`, typed as those steps' outputs.
- A step with `needs` starts when all of them have finished. No `next` has to point at it.
- `start: ['profile', 'orders']` starts both steps at once, so they run in parallel.
- To wait for a step without reading it, list it in `needs` and ignore the value. A `next` that points at a step with `needs` does not make it wait for that step.
- Keep `context` for what you know when the run is created. Pass what a step produces through `needs`.

## Decide what a skipped producer does

A step is skipped when a [branch](/guide/branch) does not choose it, when its `when` returns `false`, or when a [wait](/guide/wait) times out.

| Need | Value | If the producer is skipped |
|---|---|---|
| `needs: { a }` | The output of `a` | This step is skipped too |
| `needs: { first: { any: [a, b] } }` | The output of the first one to finish | This step is skipped only if all of them are |
| `needs: { a: { optional: a } }` | The output of `a`, or `undefined` | This step still runs |
