# Getting started

Install core and one [Standard Schema](https://standardschema.dev/) library:

```sh
pnpm add @openwizard/core zod
```

Create `order.mts`:

```ts file="packages/docs/snippets/getting-started/order.mts"
```

Run it:

```sh
pnpm tsx order.mts
```

`defineFlow` owns the context type. `steps()` checks every referenced step id. `createRun` parses
the context, starts `prepare`, follows its `next`, and returns the final output as a result value.

Read [How it works](/how-it-works) next. The complete runnable version is
[Example 11](/examples/11-order-workflow).
