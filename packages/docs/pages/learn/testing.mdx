# Testing

Create a real run and send the commands your application uses. Replace services with fakes so the test does not need a browser, server, or database.

```ts file="packages/docs/snippets/learn/testing.test.ts"
```

1. Create a run with empty context and start it.
2. Store an invalid draft.
3. Call `next()` and assert the command failed.
4. Assert the run is still on `contact`.

Assert what a user observes, such as command responses, outcomes, `status`, `current`, and calls to services. Assert an exact event sequence when event ordering is the behavior under test.

## Fake dependencies

Pass services through `deps` so the test can replace them:

```ts
const payments = {
  charge: vi.fn().mockRejectedValueOnce(new Error('busy')).mockResolvedValue({ id: 'p1' }),
}
const run = order.create(context, { deps: { payments } })
```

This fake fails once, then succeeds. Start the run and assert the completed output and number of calls. For a failure that needs manual recovery, await `run.awaitOutcome()` and assert `status: 'halted'`; `awaitResult()` will wait until you recover or cancel that run.

`createMemoryStore()` exposes `keys()` and `clear()` for persistence tests. Save a snapshot, dispose the original run, and call `wizard.resume(snapshot, options)` to check that completed work stays completed.

## Timers without waiting

```ts
import { createTestScheduler } from '@openwizard/core/testing'

const scheduler = createTestScheduler({ now: 0 })
const run = wizard.create(context, { scheduler })

await run.start()
scheduler.advance(1_000) // fires timers due by now
```

The scheduler is also the run's clock. Sleep deadlines, retry backoff, work timeouts, wait timeouts, and buffered-event expiry move with `advance()`.

Dispose every live run at the end of the test so timers and subscriptions do not outlive it. The convenience `wizard.run()` owns disposal itself.
