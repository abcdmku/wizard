# Recipes

Use these pages after the learning path when you recognize the same control-flow problem in your application. Each recipe explains what causes the run to move, where its data goes, and why that step kind fits the problem.

- [Collect form input](/recipes/form) when a person must provide valid data before work continues.
- [Choose a branch](/recipes/branching) when current data selects one path and skips the others.
- [Run work in parallel](/recipes/parallel) when independent tasks can start together but a later step needs all of them finished.
- [Use a child flow](/recipes/nested) when one stage is a workflow with its own steps, state, and tests.

Start with [how a flow becomes a running workflow](/learn/mental-model) if `defineFlow()`, context, or `next` are still new.
