# Overview

Each recipe covers one workflow pattern with a tested snippet and an explanation of its execution.

| Recipe | Use it when |
|---|---|
| [Collect form input](/recipes/form) | A person must enter valid data before the run continues |
| [Branch on data](/recipes/branching) | Current data decides which path runs |
| [Run steps in parallel](/recipes/parallel) | Independent work starts together and a typed join consumes its outputs |
| [Use a child wizard](/recipes/nested) | A stage has its own context, input, or recovery workflow |
