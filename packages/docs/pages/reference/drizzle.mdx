# Drizzle

`@openwizard/drizzle` stores durable runs in PostgreSQL or SQLite through Drizzle ORM.

```sh
npm install @openwizard/drizzle @openwizard/durable drizzle-orm
```

```ts file="packages/docs/snippets/advanced/drizzle.ts"
```

Pass the store to [`createDurableHost`](/production/server). The package opens no connection and runs no migration. Generate the migration with Drizzle Kit, as for your own tables.

| Export | From | Meaning |
|---|---|---|
| `definePgDurableSchema(options?)` | `@openwizard/drizzle/pg` | The PostgreSQL tables |
| `createPgDrizzleDurableStore(db, schema, options?)` | `@openwizard/drizzle/pg` | A `DurableStore` on a PostgreSQL database |
| `defineSqliteDurableSchema(options?)` | `@openwizard/drizzle/sqlite` | The SQLite tables |
| `createSqliteDrizzleDurableStore(db, schema, options?)` | `@openwizard/drizzle/sqlite` | A `DurableStore` on an async SQLite driver |

| Option | Of | Meaning |
|---|---|---|
| `tablePrefix` | The schema | Prefix of the table names. Default `openwizard_` |
| `leaseTtlMs`, `timerClaimTtlMs` | The store | Default 30 seconds each |
| `retention` | The store | `{ completedDedupeMs, timerClaimMs }`. A finished `commandId` is kept 7 days by default |
| `now` | The store | The clock, for tests |

Full signatures are in the [generated reference](/typedoc/modules/_openwizard_drizzle.html).
