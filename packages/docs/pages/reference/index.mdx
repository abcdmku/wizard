# Packages

Find the package for a job and its reference page.

Every application installs `@openwizard/core`. The others are optional.

| Package | Install it to | Guide |
|---|---|---|
| [`@openwizard/core`](/reference/core) | Define wizards and run them | [Quickstart](/quickstart) |
| [`@openwizard/react`](/reference/react) | Render a run with React hooks | [Show a run to a client](/production/client) |
| [`@openwizard/devtools`](/reference/devtools) | See a run's graph, events and steps in a panel | [Inspect and debug](/guide/inspect) |
| [`@openwizard/durable`](/reference/durable) | Serve a run from several processes | [Run on a server](/production/server) |
| [`@openwizard/drizzle`](/reference/drizzle) | Store durable runs in PostgreSQL or SQLite | [Run on a server](/production/server#store-runs-in-a-database) |
| [`@openwizard/http`](/reference/http) | Expose a run API and receive webhooks | [HTTP API and webhooks](/production/http) |
| [`@openwizard/effect`](/reference/effect) | Run Effect programs as steps | [Effect](/reference/effect) |
| [`@openwizard/opentelemetry`](/reference/opentelemetry) | Record runs as spans | [Tracing](/production/tracing) |

Full type signatures are in the [generated API reference](/typedoc/).
