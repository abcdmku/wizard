# React

`@openwizard/react` gives React components typed hooks over a run or a mirror.

```sh
npm install @openwizard/react
```

React 18 and 19 are supported.

```tsx file="packages/docs/snippets/packages/react.tsx"
```

| Export | Meaning |
|---|---|
| `bindReact<typeof wizard>()` | A `Provider` and hooks typed by a wizard, for a run in the same process |
| `bindReact<typeof projection>()` | The same for a [mirror](/advanced/client), typed by a projection. Adds `useConnection()` |
| `useRun(create, deps?)` | Creates a run or a mirror once, keeps it through a StrictMode remount, and disposes it on unmount |

| Member of the binding | Meaning |
|---|---|
| `Provider` | Takes `source`, a run or a mirror, and `fallback`, shown until a mirror has its first frame |
| `useSnapshot()` | The whole state. Renders again on every change |
| `useSelector(select, isEqual?)` | A value computed from the state. Renders again when it changes |
| `useCurrent()` | The record of the current view, or `null` |
| `useStep(id)` | The record of one step. For a view, also `setInput`, `resetInput`, `next`, `back`, `go` and `issuesFor(field)` |
| `useActions()` | The commands of the run or mirror |
| `useChild(step)`, `useChild(step, index)` | The same hooks for a child run, or for one item of a child step with `each` |
| `useConnection()` | `{ connected, connect }`, for a mirror |

- `next` and `back` from `useStep(id)` apply only while that view is current, so a stale component cannot move another view.
- A run that the component did not create with `useRun` stays yours to dispose.
- The `useSnapshot()` of a child returns `null` until the child exists. Check it before you render a component that calls the child's `useStep`.
- Over a mirror, `useChild` needs a projection that exposes the child with a nested `child: { ... }`.
- To render on a server, create the mirror with `createMirror({ initial, transport })`, where `initial` is the frame the server rendered with.

Full signatures are in the [generated reference](/typedoc/modules/_openwizard_react.html).
