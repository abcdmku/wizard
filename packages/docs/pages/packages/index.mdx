# Packages

Find the package for a job and its reference page.

Every application installs `@openwizard/core`. Add another package when you need what it does.

| Package | Install it to | Guide |
|---|---|---|
| [`@openwizard/core`](/packages/core) | Define wizards and run them | [Quickstart](/getting-started) |
| [`@openwizard/react`](/packages/react) | Render a run with React hooks | [Show a run to a client](/advanced/client) |
| [`@openwizard/devtools`](/packages/devtools) | See a run's graph, events and steps in a panel | [Inspect and debug](/learn/inspect) |
| [`@openwizard/durable`](/packages/durable) | Serve a run from several processes | [Run on a server](/advanced/server) |
| [`@openwizard/drizzle`](/packages/drizzle) | Store durable runs in PostgreSQL or SQLite | [Run on a server](/advanced/server#store-runs-in-a-database) |
| [`@openwizard/http`](/packages/http) | Expose a run API and receive webhooks | [HTTP API and webhooks](/advanced/http) |
| [`@openwizard/effect`](/packages/effect) | Run Effect programs as steps | [Effect](/packages/effect) |
| [`@openwizard/opentelemetry`](/packages/opentelemetry) | Record runs as spans | [Tracing](/advanced/tracing) |

Full type signatures are in the [generated API reference](/typedoc/).
