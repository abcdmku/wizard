# Examples

Run a complete project that shows one feature, or read a larger system.

```sh
git clone https://github.com/abcdmku/wizard && cd wizard
pnpm install && pnpm build
pnpm --filter example-01-happy-path start
```

Each example lives in `examples/<name>` with a wizard, a `main.ts` and a test. Replace `start` with `check` to type-check and test it. For a row marked "dev", use `dev` in place of `start`.

## Read a larger system

Four systems in `systems/` run with Docker Compose. Each README lists the commands, ports and demo accounts.

| System | Shows |
|---|---|
| [Grant intake](https://github.com/abcdmku/wizard/blob/main/systems/01-intake/README.md) | A resumable form for applicants, a projection for reviewers, and a background worker |
| [Fleet dispatch](https://github.com/abcdmku/wizard/blob/main/systems/02-fleet/README.md) | A dispatch console fed by a projection over server-sent events |
| [Fulfillment](https://github.com/abcdmku/wizard/blob/main/systems/03-fulfillment/README.md) | An order across a browser, an HTTP service, durable runs, queues and a signed callback |
| [Dungeon](https://github.com/abcdmku/wizard/blob/main/systems/04-dungeon/README.md) | A multiplayer room where the server owns the state and PostgreSQL keeps it across restarts |
