# OpenTelemetry

`@openwizard/opentelemetry` turns automatic run events into workflow, task-attempt, and
compensation spans.

```sh
pnpm add @openwizard/opentelemetry @opentelemetry/api
```

```ts file="packages/docs/snippets/http/telemetry.ts"
```

This imports the example flow from the [run API guide](/integrations/run-api).

Attach instrumentation before starting the run. Call `telemetry.stop()` when the application no
longer owns it. The integration records stable lifecycle fields, not context, input, output,
payloads, commands, or error messages.

For incoming messages, extract their trace context before calling `telemetry.send`. See the
[OpenTelemetry API](/api/opentelemetry) for resume links, child runs, and event controls.
