# Integrations

Start with [HTTP and webhooks](/integrations/webhooks) if another process needs to read, command,
or send events to a run.

| Integration | Use it for |
|---|---|
| [Run REST API](/integrations/run-api) | authenticated reads and commands |
| [Incoming webhooks](/integrations/incoming-webhooks) | signed input events from another system |
| [Outgoing webhooks](/integrations/outgoing-webhooks) | automatic run events sent to tenant callbacks |
| [Drizzle](/integrations/drizzle) | PostgreSQL or SQLite durable coordination |
| [React](/integrations/react) | typed hooks over a run or client mirror |
| [Effect 3](/integrations/effect) | Effect programs as flow tasks |
| [Effect 4 beta](/integrations/effect-v4) | Effect 4 beta programs as flow tasks |
| [OpenTelemetry](/integrations/opentelemetry) | run, task, and compensation spans |

Each adapter is optional. The core concepts remain the same as the
[getting started flow](/getting-started).
