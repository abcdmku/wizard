# Runnable examples

Every example is a small package under `examples/<name>` with a wizard, a runner, and a test.

Run one from the repository root:

```sh
pnpm --filter example-01-happy-path start
```

Type-check and test it with `check`:

```sh
pnpm --filter example-01-happy-path check
```
