# Examples

These workspace packages turn the concepts into runnable code. Read them in order, or jump to the
first topic you need.

| Example | Covers |
|---|---|
| [01: Happy path](/examples/01-happy-path) | one view, one task, validation, and a final result |
| [02: Recoverable failure](/examples/02-recoverable-failure) | retries, idempotency, typed errors, and virtual time |
| [03: Compensation](/examples/03-non-recoverable-compensation) | reverse-order cleanup after a failure |
| [04: Resume from snapshot](/examples/04-resume-from-snapshot) | save, stop, resume, restore timers, and migrate |
| [05: Input events](/examples/05-external-events) | typed input events, buffering, timeouts, and correlation |
| [06: Nested flow](/examples/06-nested-flow) | child runs, commands, events, snapshots, and mirrors |
| [07: Parallel work](/examples/07-dag-pipeline) | branches, joins, concurrency, skipping, and `explain()` |
| [08: React and Mirror](/examples/08-react-mirror) | a projected run over a serialized loopback transport |
| [09: Mermaid](/examples/09-mermaid) | rendering a static flow graph |
| [10: Devtools](/examples/10-devtools) | graph, events, inspector, and timeline in a live app |
| [11: Backend order workflow](/examples/11-order-workflow) | retries, events, persistence, and compensation together |
| [12: Pulumi database binding](/examples/12-pulumi-infrastructure) | validating stack configuration and preserving a secret URL |
| [13: Deployment artifacts](/examples/13-deployment-artifacts) | building one Nitro host for seven runtime targets |

From the repository root:

```sh
pnpm install
pnpm build
pnpm examples
```

Each page links the exact source and test. Examples 01 through 07, 09, and 11 also run in the
[playground](/playground).
