# Boundaries

A boundary turns untrusted input into data the flow can use. OpenWizard accepts any Standard
Schema library, including Zod, Valibot, and ArkType.

| Input | Boundary |
|---|---|
| initial context | `defineFlow({ context })` |
| view draft | `view({ input })` |
| input event | `defineFlow({ events })` |
| restored context, drafts, outputs, and inbox payloads | their original boundaries |

```ts file="packages/docs/snippets/concepts/boundaries.ts"
```

Use `boundary.trusted<T>()` only for values the host constructs and already trusts. Use
`boundary.parse`, `boundary.guard`, or `boundary.assert` when you do not have a Standard Schema.
Async boundaries require `createRunAsync` and `resumeRunAsync`.

Keep secrets in dependencies, not context or step outputs. Persisted state must survive a JSON
round trip. [Persistence](/concepts/persistence) explains the exact rule.
