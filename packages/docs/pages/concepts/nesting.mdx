# Nested flows

A `flow` step runs a child flow with its own context, state, input events, and final output.

```ts file="packages/docs/snippets/concepts/nesting.ts"
```

`run.child('fulfil')` returns the live child after that step starts. Child events reach the
parent's observer with a path such as `['fulfil']`. The parent step completes when the child
finishes, or fails when the child fails. The child snapshot sits inside the parent snapshot, so
both resume together.

The parent can map context and dependencies into the child, validate its output, and compensate
the child as one unit. Nesting is limited to eight levels, and a flow cannot contain one of its
ancestors.

Client commands and projections identify descendants with the same path. Next, persist the server
run in [Persistence and resume](/concepts/persistence).
