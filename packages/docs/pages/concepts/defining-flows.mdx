# Defining flows

`defineFlow(options)` declares the flow's identity, boundaries and policies, and returns a
`FlowBuilder`: the six step constructors plus `steps()`.

```ts
import { boundary, defineFlow } from '@openwizard/core'
import { z } from 'zod'

interface Deps {
  payments: { charge(cartId: string, total: number): Promise<{ paymentId: string }> }
}

const s = defineFlow({
  name: 'checkout', // name plus version is the persistence identity, checked on resume
  version: 1,
  context: z.object({ cartId: z.string(), total: z.number(), paymentId: z.string().optional() }),
  events: { 'payment.captured': z.object({ paymentId: z.string() }) },
  deps: boundary.trusted<Deps>(), // the host builds deps, so there is nothing to check
  onFailure: 'compensate',
})
```

`s` carries those types, so every hook below is typed without a single generic.

```ts
export const checkout = s.steps(
  {
    shipping: s.view({ input: z.object({ address: z.string().min(1) }), next: 'reserve' }),
    reserve: s.task(({ context, deps }) => deps.inventory.reserve(context.cartId), {
      retry: { attempts: 3, backoff: 'exponential' },
      compensate: ({ output, deps }) => deps.inventory.release(output.reservationId), // undo it later
      next: 'awaitPayment',
    }),
    awaitPayment: s.wait({
      on: { 'payment.captured': ({ payload, update }) => update({ paymentId: payload.paymentId }) },
      timeout: { after: '15m', next: 'expired' },
      next: 'route',
    }),
    route: s.decision({ next: ({ context }) => (context.paymentId ? 'receipt' : 'expired') }),
    receipt: s.final({ output: ({ context }) => ({ paymentId: context.paymentId }) }),
    expired: s.final(),
  },
  { start: 'shipping' }, // defaults to the first declared step; an array starts several at once
)
```

## `defineFlow(options)`

| Option | Type | What it does |
|---|---|---|
| `name` | `string` (required) | The flow's identity. With `version` it is checked on resume. |
| `version` | `number` (default `1`) | Bump it when the step set changes in a way old snapshots can't survive. |
| `context` | `Boundary<C, CIn>` (required) | Parsed at `createWizard({ context })` and again on resume. |
| `events` | `{ [name]: Boundary }` | What `send(name, payload)` accepts and what `on` handlers can listen for. |
| `deps` | `Boundary<D>` | What `createWizard({ deps })` must receive, required exactly when the flow declares it. |
| `on` | `{ [event]: handler }` | Flow-level handlers, run after the step-level ones for the same event. `{ cancel: reason }` cancels the flow. |
| `correlate` | `{ [event]: (payload) => string \| undefined }` | With `createWizard({ correlationId })`, an event whose id doesn't match is dropped: `event.dropped { reason: 'correlation' }`. |
| `onFailure` | `'halt' \| 'compensate'` (default `'halt'`) | What happens when a task fails with no retries left. |
| `retry` | `RetryPolicy` | The default retry policy for tasks. |
| `autoRun` | `'ready' \| 'manual'` (default `'ready'`) | Ready non-view steps start on their own, or wait for `runReady()`. |
| `concurrency` | `number` (default `Infinity`) | The most tasks that can run at once. |
| `unmatchedEvents` | `{ buffer: boolean; ttl: Duration }` | Events with no listener are buffered in arrival order, or dropped. Default: buffer for `'5m'`. |

A `Duration` is milliseconds as a number or a string like `'250ms'`, `'15s'`, `'15m'`, `'2h'` or
`'1d'`. The `Flow` that `steps()` returns is plain data: `inspect(flow)` shows its graph, and
`createWizard(flow, ...)` is what runs it.

## Hook arguments

Every hook receives `BaseArgs<C, D>`, and each hook adds a little on top.

| Field | On | What it is |
|---|---|---|
| `context: C` | all | The parsed flow context, fully typed. |
| `update(patch)` | all | Patches the context (shallow merge, `context.changed`). How steps hand typed data to each other. |
| `deps: D` | all | Whatever `createWizard({ deps })` received. |
| `steps` | all | Sibling records, an open map (`SiblingStates`) of `unknown` input and output. Use `context` for typed data. |
| `step`, `path` | all | This step's id and the wizard path: `[]` at the root, `['fulfil']` inside a child. |
| `signal` | all | An `AbortSignalLike`, aborted on timeout, cancel or dispose. |
| `attempt`, `idempotencyKey` | `run`, `idempotent`, `mapError` | The 1-based attempt number and the run's idempotency key. |
| `from` | `enter`, `canEnter` | The previous step, or `null`. |
| `output` | `validate`, `canExit`, `exit`, `next`, `compensate` | The step's parsed or produced output. |
| `to`, `direction` | `exit` | The target step and `'forward'` or `'back'`. |
| `reason` | `compensate` | Why the saga is running, if `cancel(reason)` gave one. |
| `event`, `payload` | `on[event]`, any kind or flow-level | The event name and its parsed payload. |
| `error` (first argument) | `mapError` | The raw thrown value or rejection from the failed run. |

Hooks can be sync or async. Pass `strict: 'sync'` to `createWizard` and any hook returning a
thenable becomes a `SYNC_VIOLATION` failure.

## What does not compile

`steps()` checks every id a step mentions against the keys of the steps object, and the error
lands on the property you got wrong rather than on the whole call.

```ts
s.steps({ shipping: s.view({ next: 'typo' }) }) // error on `next`: unknown step id
wizard.setInput('typo', { address: '1 Main St' }) // 'typo' is not a view of this flow
wizard.go('reserve') // `go` only takes view ids, and 'reserve' is a task
wizard.send('payment.refunded', {}) // the flow never declared that event
```

## Type extractors

One extractor per concept, for naming a flow's types elsewhere: `StepId<F>`, `ViewId<F>`,
`TaskId<F>`, `ChildStepId<F>`, `Ctx<F>`, `ContextInput<F>`, `DepsOf<F>`, `EventType<F>`,
`PayloadOf<F, E>`, `InputOf<F, K>`, `DraftOf<F, K>`, `OutputOf<F, K>`, `ErrorOf<F, K>`,
`ChildFlowOf<F, K>` and `FlowOutput<F>`.

```ts
import type { DraftOf, OutputOf, StepId } from '@openwizard/core'

type Ids = StepId<typeof checkout> // 'shipping' | 'reserve' | 'awaitPayment' | 'route' | ...
type ShippingDraft = DraftOf<typeof checkout, 'shipping'> // { address?: string }
type ReserveOutput = OutputOf<typeof checkout, 'reserve'> // { reservationId: string }
```
