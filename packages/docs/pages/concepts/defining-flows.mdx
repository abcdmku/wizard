# Defining flows

`defineFlow` captures the context, dependency, and input-event types. Its step constructors carry
those types into every hook.

Save this example as `order-definition.ts`:

```ts file="packages/docs/snippets/concepts/order-definition.ts"
```

The returned `orderFlow` does nothing until `createRun(orderFlow, ...)` creates a live run. Its
name and version are stored in each snapshot. By default, the first declared step is the start.
Pass `{ start: 'stepId' }` to `steps` to choose another one.

TypeScript checks step ids used by `next`, `dependsOn`, timeout targets, commands, and client
bindings. Types such as `Ctx<F>`, `StepId<F>`, `OutputOf<F, K>`, and `FlowOutput<F>` come from the
assembled flow.
