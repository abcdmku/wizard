# Runtime guarantees

Design around these rules:

- The flow owns ids and data types. Runtime [boundaries](/concepts/boundaries) parse context,
  input events, view drafts at validation, and stored values at resume.
- Commands return [result values](/concepts/results). `WizardError` reports misuse or an invalid
  runtime contract.
- Subscribers receive [run events](/concepts/observability) only after the complete batch commits.
- Snapshots are checked before storage and again on [resume](/concepts/persistence).
- External effects are at least once. Use the stable idempotency key described in
  [Failures and retries](/concepts/policies).
- Core storage has one owner per key. Use the [durability guide](/guides/durability) for worker
  handoff and fenced writes.

The [core API reference](/api/core) lists the complete public surface. The [examples](/examples)
exercise the same contracts with runnable tests.
