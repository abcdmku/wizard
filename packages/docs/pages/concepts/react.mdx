# React

`@openwizard/react` binds hooks to a local `FlowRun` or a client `Mirror`. Browser applications
should normally use the projected Mirror from the previous page.

```tsx file="packages/docs/snippets/concepts/app.tsx"
```

`publicOrder` is the projection from [Projections and the Mirror](/concepts/projections). The app
receives its connected `Mirror`. Transport setup stays outside the component.

`useStep(id)` returns one typed step and its bound actions. `useSelector` subscribes to a derived
slice. `useChild(step)` creates hooks for an exposed child flow. All hooks use
`useSyncExternalStore`, so they read one committed snapshot at a time.

Do not put card numbers, access tokens, or other secrets in view drafts. Tokenize them first, then
send only the safe reference into the run.

The [React integration](/integrations/react) covers installation and server rendering. Continue
with [Testing](/concepts/testing).
