# Testing

Test the real flow with in-memory dependencies. Assert the result, state, and committed run
events.

```ts file="packages/docs/snippets/concepts/order.test.ts"
```

The imported flow and `Deps` type come from [Defining flows](/concepts/defining-flows). The test
supplies the only external service that flow declares.

`createTestScheduler()` supplies virtual time for retries, wait deadlines, and inbox expiry.
`createLocalTransport()` connects a `MirrorSource` to a Mirror without a server and can force a
JSON round trip.

Add `*.test-d.ts` files for guarantees that exist only at compile time, such as rejected step ids
or inferred task outputs. Use the normal TypeScript checker so each `@ts-expect-error` must match a
real error.

Finish with the [Runtime guarantees](/concepts/guarantees) contract.
