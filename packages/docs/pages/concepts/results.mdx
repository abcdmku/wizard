# Results as values

Operations that can be rejected during normal use return discriminated results. When a run
finishes, `awaitResult()` returns a `RunResult`.

```ts file="packages/docs/snippets/concepts/submit-address.ts"
```

The function accepts the flow assembled on [Steps and kinds](/concepts/steps). Passing the run in
keeps creation, dependencies, and ownership outside the example.

Navigation returns `NavResult`. `send` returns `SendResult`. Other commands return
`CommandResult`. Pure reads such as `getState`, `validate`, `explain`, and `progress` do not change
the run.

`WizardError` reports invalid definitions, programmer mistakes, lifecycle misuse, and incompatible
snapshots. Use `isWizardError` when catching one at an application boundary.
