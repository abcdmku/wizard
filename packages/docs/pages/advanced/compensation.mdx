# Undo completed side effects in a known order

A database transaction cannot cover an airline, hotel, car provider, and payment API. If the fourth call fails, the first three systems may already hold real reservations.

The trip example gives each completed reservation a compensation function and sets `onFailure: 'compensate'`:

```ts file="examples/03-non-recoverable-compensation/src/book-trip.ts"
```

## OpenWizard records what actually completed

The runtime pushes a task onto the saga stack only after that task succeeds. It stores the task output that its compensation function will need later.

If `charge` fails, the recorded stack is:

```text
reserveFlight -> reserveHotel -> reserveCar
```

OpenWizard compensates in reverse completion order:

```text
cancel car -> cancel hotel -> cancel flight
```

Reverse order matters when a later reservation depends on an earlier one. It also means a skipped or never-started task is not compensated.

## Compensation can fail too

A hotel cancellation may fail while the car cancellation succeeds. OpenWizard records the failed compensation, continues unwinding the remaining entries, and finishes with the failure list in saga state and the terminal result.

After the hotel system recovers, an operator can retry only that entry:

```ts
await run.compensate({ from: 'reserveHotel' })
```

The selected hook receives the original task output again. Make each compensation idempotent when its outside service supports a request key.

## This is a recovery plan, not time travel

Compensation performs new business actions. A refund does not make a charge disappear. A cancellation may have a fee. Another system may have observed the original reservation.

Write compensation functions that match those business facts. OpenWizard supplies the completion order, stored outputs, failure tracking, and retry command. Your application decides what "undo" means for each service.

Use the default recoverable halt when a human should repair the failed task and continue forward. Use `onFailure: 'compensate'` when the failed path must become terminal and earlier side effects should be unwound.
