# API reference

Read the guides first, then use these generated references for exact signatures and types.

- [`@openwizard/core`](/api/core) defines flows, runs, events, and projections. Start with
  [getting started](/getting-started).
- [`@openwizard/durable`](/api/durable) coordinates persisted runs across workers. Read the
  [durability guide](/guides/durability).
- [`@openwizard/drizzle`](/api/drizzle) stores durable runs in PostgreSQL or SQLite. See the
  [Drizzle integration](/integrations/drizzle).
- [`@openwizard/effect`](/api/effect) adapts Effect 3 programs. See the
  [Effect 3 integration](/integrations/effect).
- [`@openwizard/effect-v4`](/api/effect-v4) adapts Effect 4 beta programs. See the
  [Effect 4 integration](/integrations/effect-v4).
- [`@openwizard/react`](/api/react) binds runs and Mirrors to React. See the
  [React integration](/integrations/react).
- [`@openwizard/opentelemetry`](/api/opentelemetry) records run events as spans. See the
  [OpenTelemetry integration](/integrations/opentelemetry).
- [`@openwizard/webhooks`](/api/webhooks) builds signed webhooks and authenticated run APIs. Start
  with [HTTP and webhooks](/integrations/webhooks).
