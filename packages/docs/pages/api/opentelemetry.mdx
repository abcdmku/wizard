# OpenTelemetry API

The generated [`@openwizard/opentelemetry` reference](/typedoc/modules/_openwizard_opentelemetry.html) covers `instrumentRun`, its options, and the instrumentation handle.

Read the [OpenTelemetry guide](/packages/opentelemetry) first.

| Export | Purpose |
|---|---|
| `instrumentRun(run, options?)` | Attach spans to a run |
| `InstrumentRunOptions` | `tracer`, `parentContext`, `resumeContext`, `children`, `recordEvents`, `instanceId`, `onError`, `successStatus` |
| `RunInstrumentation` | Handle with `stop()`, `span()`, `context()`, `inject()`, `extract()`, `send()` |
| `ExternalSendOptions` | `eventId`, `correlationId`, and incoming trace `context` for `send()` |

`telemetry.send(event, payload, options)` forwards the event and correlation ids to `run.send`. A repeated remembered `eventId` gets the run's duplicate result; tracing does not create a second event delivery.
