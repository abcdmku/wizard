# Effect API

The generated [`@openwizard/effect` reference](/typedoc/modules/_openwizard_effect.html) covers the Effect 4 run adapter, runtime dependencies, and JSON error mapping.

Read the [Effect guide](/packages/effect) first.

| Export | Purpose |
|---|---|
| `runEffect(program, { mapError? })` | Adapter for `step({ run: ... })`; uses `args.deps.runtime` |
| `EffectDeps<Services, RuntimeError>` | Services and runtime-layer error carried by wizard deps |
| `RunEffectOptions` | Maps typed program or runtime-layer failures to JSON error data |
| `RuntimeErrorOf<Deps>` | Extracts the runtime-layer error type |

The program receives typed step args and returns an Effect whose services must be supplied by the runtime. Output is the program's success value. The step's abort signal interrupts the fiber on timeout, cancellation, or disposal. Supply the runtime per run or with `wizard.provide({ runtime })`; dispose it during application shutdown.

`step({ run: runEffect(program), output, mapError })` can override adapter defaults. The output boundary replaces the adapter's boundary. The mapper receives the original failure, replaces stored JSON error data, and supplies that mapped data to `retry.when`.

For item or joined data, use `run: args => runEffect(() => program(args.item, args.needs))`. The step callback infers its arguments before creating the adapter. Declare static `step.output` to restore parsed values such as Dates from saved JSON; returned-adapter metadata validates execution but does not replace a restore schema.
