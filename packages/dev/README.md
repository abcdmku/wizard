# @openwizard/dev

A local dev server and browser UI for wizards. It shows each wizard's graph, steps and schemas, starts runs, and lets you supply everything a run waits for by hand.

```sh
npm install -D @openwizard/dev
npx openwizard dev src/refund.ts
```

Open `http://127.0.0.1:4400`. The server reloads the wizards when a file they import changes.

In a run you can:

- fill in a form and see what its schema refuses
- send an event with a payload
- answer a service call with a return value, or make it throw
- skip to the next sleep, timeout or retry delay
- retry or skip a failed step, and cancel the run
- stop the run and resume it from its snapshot, as a restarted process would

Each kind of wait has its own badge: Form, Webhook, Queue event, Event, Service call and Timer.

To give a wizard real services, a starting input, the sender of each event and the values its editors open with, export a config:

```ts
import { defineDev, devWizard } from '@openwizard/dev'
import { refund } from './src/refund'

export default defineDev({
  wizards: [
    devWizard(refund, {
      input: { orderId: 'o-2' },
      events: { 'refund.approved': { source: 'webhook', from: 'Back office' } },
      examples: { calls: { 'orders.find': { total: 250 } } },
    }),
  ],
})
```

Runs live in the server's memory. Use it on your own machine only. It has no sign-in.

Read the [dev server guide](https://abcdmku.github.io/wizard/guide/dev).
